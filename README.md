## Секции сайта
1. **Hero** - главный экран с фоновым изображением, заголовком и кнопкой перехода к расписанию.
2. **История** - двухколоночный блок (фото + текст) с историческими фактами.
3. **Достопримечательности** - шесть карточки с изображениями, названиями и описаниями.
4. **Слайдер отзывов** - карусель с 6 отзывами.
5. **Форма обратной связи** - поля для имени, email и сообщения с кастомной валидацией.
6. **Карта** — интерактивная Яндекс.Карта с меткой и всплывающим окном.
7. **Футер** — ссылки на разделы, контакты и копирайт.

## Адаптивность
Десктоп (1200px) 
Планшет (768)
Телефон (390px)

## Запуск проекта
1. Скачайте папку `my_site` 
2. Откройте файл `index.html` в любом современном браузере.
3. Рекомендуется использовать **Live Server** в VS Code для полной функциональности
