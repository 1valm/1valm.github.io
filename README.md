## Секции сайта
**Hero** - главный экран с фоновым изображением, заголовком и кнопкой перехода к расписанию.
**История** - двухколоночный блок (фото + текст) с историческими фактами.
**Достопримечательности** - шесть карточки с изображениями, названиями и описаниями.
**Слайдер отзывов** - карусель с 6 отзывами.
**Форма обратной связи** - поля для имени, email и сообщения с кастомной валидацией.
**Карта** — интерактивная Яндекс.Карта с меткой и всплывающим окном.
**Футер** — ссылки на разделы, контакты и копирайт.

## Адаптивность
Десктоп (1200px) 
Планшет (768)
Телефон (390px)

## Запуск проекта
1. Скачайте папку `my_site` 
2. Откройте файл `index.html` в любом современном браузере.
3. Рекомендуется использовать **Live Server** в VS Code для полной функциональности
